## 🎯 **How to Use**

### **For Buyers:**

1. **Browse to any car** (e.g., `/cars/40` for McLaren)
2. **Hover over main image** → See "VIEW IN 3D" button
3. **Click the button** → 3D viewer opens fullscreen
4. **Interact:**
   - **Drag**: Rotate camera around car
   - **Scroll**: Zoom in/out
   - **Shift+Drag**: Pan camera
5. **Toggle info panel** with INFO button
6. **Close** when done

### **3D Viewer Controls:**
- 🖱️ **Left mouse drag** = Rotate
- 🖱️ **Scroll wheel** = Zoom
- 🖱️ **Shift + drag** = Pan
- 📱 **Touch**: One finger rotate, pinch zoom
